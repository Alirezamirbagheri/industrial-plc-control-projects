# TwinCAT Source Excerpts

These files are intentionally reduced, portfolio-safe excerpts from the reviewed TwinCAT offline spline-execution project.

- [`cyclic_spline_generation.st`](cyclic_spline_generation.st) shows how imported segment weighting and a requested total motion time are converted into cyclic interpolation steps, followed by cubic X/Y spline evaluation.

The complete native project is not included. Machine-specific paths, XPlanar configuration, compiled/vendor libraries, TwinSAFE content, license material and generated build artifacts remain excluded.

The offline spline coefficients and motion-allocation metadata are generated by the companion [`../python-preprocessing/`](../python-preprocessing/) stage.
